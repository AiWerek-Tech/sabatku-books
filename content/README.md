# Published book content

This public repository contains approved hosted reading editions in Indonesian and English, including *Kasih di Tengah Kobaran Konflik / Love Under Fire*. Drafts, internal QA files, and private permission documents stay outside the repository. Each edition's publication, attribution, and offline rights are recorded in its metadata. A work may also list genuinely provider-hosted editions in its catalog; those entries contain official source links only and never copy provider text. Studio publishing is postponed for lack of hosting/server budget; this repository currently publishes through GitHub Pages.
