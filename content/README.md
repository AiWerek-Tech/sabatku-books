# Published book content

This public repository contains the approved Indonesian reading text. Drafts, internal QA files, English source text, and private permission documents stay outside the repository. A work may list provider-hosted editions in other languages in its catalog metadata; those entries contain source links only and never copy the provider's text. The catalog exposes the Indonesian SabatKu edition and the official English EGW Writings edition as two language choices for *Love Under Fire*.
